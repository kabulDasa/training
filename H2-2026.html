Lift Settings
Current working prescriptions and progression rules, one per movement and variant. Loads update as you log sessions. Edit a rule to switch between a top set + backoff and straight sets, linear and double progression, or change its increments, rep cap and backoff; each change is a commit to progress.md, shared by every device.
Weighted pull-up and dip loads are added belt weight. Squat load is bar weight.
Your exercises
Add an exercise to the program: its name (also its session-log name), day, type, movement pattern and load kind, its progression rule and its starting working set are all required; muscles are optional. It then shows on the Program tab, Today Plan, presets, Chart and Sync to Notes like the program's own movements. Edit changes its details and rule; Retire hides it from the program but keeps its log and stats (Restore brings it back); Delete is only possible while it has no logged sessions. Each change is a commit to progress.md.
