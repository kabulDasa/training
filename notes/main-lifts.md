# Main lifts: issues and troubleshooting

One section per main lift: where it stands, the open issue, and what we're doing about it. Live numbers
are in `progress.md` on the `data` branch (the H2 tracker); this file holds the *why* behind them.
Update it whenever an issue is spotted, a fix is tried, or a fix is dropped. Close an issue by moving it to
the lift's "Resolved" list with the date and what worked.

## Program-wide (2026-11-09)

**Issue: main lifts stalling.** Pull-up and dip each added 1.25 kg every session for three sessions
(pull-up +23.75 → +26.25, dip +26.25 → +28.75), then the backoff sets fell to 1 and 0. Each lift was
trained about once a week, so frequency is not the cause; per-session linear progression ran its course,
with a lot of extra pulling on the pull-up day.

**Changes:**
- Reset about 5%: pull-up +23.75 kg, dip +26.25 kg
- Backoff sets ×3 at 85% (was ×5 at 80%)
- Progress the top set only when it felt RPE 8 or easier (about 2 reps left) and the backoff sets were done
- Back to a 3-day split (push / pull / legs + accessories); some pull/push accessories moved to leg day
- Later: taper the top set toward singles for a test or competition day (peak planner on the H2 page)

**Watch:** if the top triple is RPE 9+ two weeks running after the reset, cut a backoff set before cutting load.

## Weighted pull-up

**Current (2026-11-09):** top set 3 @ +26.25 kg, 1×5 backoff (hold) → reset to +23.75 kg

### Open: weak at the top (strong start, slow finish to chin over bar)
- **Paused pull-ups in the warm-up:** at bodyweight, hold 2–3 s with the chin over the bar (the H2 page
  shows this as a reminder on the bodyweight warm-up set).
- If still weak after 4–6 weeks, add one of:
  - top-position holds at about +30 kg, 5–10 s (jump or step up)
  - 3–5 s lowering from the top
  - chest-to-bar pull-ups (pulling past the competition range)
- Accessories: hammer curls in place of one curl variation; scapular pull-ups or straight-arm pulldowns.
- Cue: "elbows down into your back pockets, chest to the bar."

## Weighted dip

**Current (2026-11-09):** top set 3 @ +28.75 kg, 0 backoff sets (hold) → reset to +26.25 kg

### Open: unstable / light-headed on heavy sets
Same pattern as heavy deadlift singles before: the fix is time under heavy loads.
- **Top set → hold → backoff sets.** After the top triple, a supported lockout hold at the same weight
  (10–15 s), then the backoff sets. The H2 page shows the hold in the Today Plan.
- Breathe: a fresh breath at the top before each rep. Don't hold one breath for the whole set, and don't
  pause long at lockout while braced.
- Eat and drink before training; stand up slowly after the set.
- **See a doctor** if it starts happening at lighter loads, or you get close to passing out.
